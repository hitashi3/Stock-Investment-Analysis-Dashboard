# Stock Investment Analysis Dashboard using Advanced Excel

## Overview

This project presents an interactive stock investment analysis dashboard developed in Microsoft Excel to help users monitor investment performance and gain meaningful financial insights through dynamic visualizations and reports.

## Technologies Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Advanced Excel Formulas
* Conditional Formatting
* Slicers

## Project Workflow

* Cleaned and transformed raw financial data to improve consistency and reporting accuracy.
* Designed an interactive dashboard using Pivot Tables and Pivot Charts for efficient data analysis.
* Implemented advanced Excel formulas and functions to calculate investment metrics and summarize financial information.
* Integrated slicers and filters to enable dynamic exploration of stock performance.
* Created visual reports to support investment monitoring and informed financial decision-making.

## Key Outcome

Built a user-friendly dashboard that converts raw stock data into actionable insights, enabling efficient tracking and analysis of investment performance.
